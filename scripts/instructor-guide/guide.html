강의 목표

강의가 끝나면 참석자가 다음 날 자기 업무에 Claude를 하나 이상 쓸 수 있다.

계속 반복할 메시지 3가지

  • 역할 + 상황 + 요청 + 출력 형식으로 쓰면 결과가 좋아진다.
  • AI 결과는 초안이다. 숫자·품번은 원본과 대조한다.
  • 가상 자료로 연습하고, 실제 자료는 회사 규칙 안에서 쓴다.

세션 1. Claude 기초

15분 · 90분안 10분

목표 로그인하고, 공식에 맞춘 질문 하나를 해 보고, 대화로 한 번 고쳐 본다.

분내용방식
0–3AI 챗봇이 잘하는 것(글·요약·표·파일 분석)과 확인이 필요한 것(최신 사실·계산). Claude.ai 화면: 새 대화, 📎 첨부, 아티팩트, 프로젝트시연
3–6나쁜 예 납기 지연 메일 써줘와 좋은 예(모음집 맨 위)를 나란히 실행 → 역할 + 상황 + 요청 + 출력 형식시연
6–8보안 수칙: 도면·실제 단가·개인정보·미공개 계약은 넣지 않는다. 회사·고객사 이름은 가명강의
8–14필수 모음집 ①이나 부록 A에서 자기 부서 프롬프트를 골라 [ ]만 바꿔 실행 → "다듬기 한마디"로 한 번 더실습
14–152~3명 결과를 화면으로 공유공유

짚을 점

  • 한 번에 완벽하게 쓰지 않아도 된다. 대화로 고치는 것이 요령.
  • 답에 숫자·법령·규격이 있으면 반드시 확인.

체크포인트 모두 답을 하나 받았는가. 막힌 사람은 옆 사람과 함께.

넘어가는 말: "글은 이 정도면 됩니다. 이제 매일 쓰는 엑셀로 가 보죠."

세션 2. 엑셀 × Claude

20분 · 90분안 15분

목표 지저분한 목록을 규칙을 주고 정리하게 하고, 필요한 함수를 버전에 맞게 받아 쓴다.

파일: 참석자 부품목록_실습.xlsx (부품목록 31행 · 단가표 25 · 출고내역 7~9월 67건), 강사 부품목록_정답.xlsx

분내용방식
0–1파일 소개: 여러 사람이 입력해서 엉망이 된 부품목록시연
1–2이 엑셀 정리해줘만 보내 보기 → 결과가 사람마다 다름실습
2–8필수 실습 1 규칙 7가지 프롬프트(부록 B) → 정리 결과 검수실습
8–14필수 실습 2 단가 찾아오기 함수(버전 넣어서) → 9월 출고량 SUMIFS실습
14–16정리 전 목록에 같은 함수를 넣으면 "단가 없음"이 나오는 모습 → 정리하는 이유시연
16–19매크로: 보고서 서식 VBA → Alt+F11 → 모듈 → F5 → .xlsm 저장시연
19–20정리: 규칙을 주고, 버전을 알려주고, 검수한다강의

짚을 점

  • 규칙을 적어 주면 결과가 일정해진다. 이 규칙 목록이 그대로 팀의 데이터 입력 기준이 된다.
  • 1,5처럼 사람도 헷갈리는 값은 AI도 추측하면 안 된다. "애매하면 표시하라"고 시킨다.
  • 함수는 내 엑셀 버전을 알려주고 받는다.
  • 매크로는 보안 경고·회사 정책으로 막힐 수 있다. 참석자는 결과만 본다.

체크포인트 (정답은 부록 B)

  • 실습 1: 부품 25개, 확인 필요 4건 (1,5 SK-SB-003, 약 80 SK-AD-006, 1백20 SK-CS-002, 빈 칸 SK-PD-004)
  • 실습 2: 9월 출고 없는 부품 11개, 7~9월 출고 합계 2,738개

90분안 실습 1(규칙 버전만) 6분 + 실습 2(찾아오기 함수만) 5분 + 매크로는 결과 화면만 2분 + 정리 2분

넘어가는 말: "엑셀 파일은 이렇게 다룹니다. 그런데 종이 서류는요? 거래명세서를 손으로 옮겨 적고 계시죠."

세션 3. 서류 사진 → 표

15분 · 90분안 10분

목표 거래명세서 사진을 표로 바꿔 엑셀에 옮기고, 숫자로 검수하는 습관을 들인다.

분내용방식
0–1문제 제기: 거래명세서를 손으로 옮기는 시간과 실수강의
1–5필수 sample-01-resin.png → 표 (프롬프트 부록 B)실습
5–7필수 탭 구분으로 받아 엑셀 A1에 붙여넣기실습
7–10필수 검수: 행 수 4 · 수량 합계 75를 서류 합계 칸과 비교. 0/O, 1/I 조심실습
10–13응용 하나: 귀사 품번 빈 서류(sample-02) 또는 처음 보는 품목(sample-03)실습
13–14손글씨 양식을 찍어 올려 틀리는 곳 확인 → 검수가 필요한 이유시연
14–15앱 연결 예고: 같은 사진을 앱 "서류 사진으로 입고"에 올리는 모습 30초시연
  • 필요한 열만 지정하고, 단가·금액은 빼라고 시킨다.
  • "읽기 어려운 칸은 추측하지 말고 '확인 필요'": 그럴듯한 오답을 막는 한 줄.
  • 응용: 납품서, 검사성적서, 명함, 손글씨 재고 장부.

넘어가는 말: "서류를 데이터로 바꿨으니, 이제 물건에 데이터를 붙여 볼까요? 바코드입니다."

세션 4. 바코드 라벨 만들기

15분 · 90분안 10분

목표 말로 설명해서 라벨 생성기를 만들고, 출력한 라벨이 실제로 스캔되는 것을 본다.

분내용방식
0–2Code128(짧은 글자, USB 스캐너) vs QR(스마트폰). 품번 체계 SK-분류-번호 = 바코드 내용강의
2–8필수 라벨 생성기 프롬프트(부록 B) → 품번 5개 → 라벨 확인실습
8–11다듬기 하나: "QR도 같이" / "품명과 보관 위치도" / "A4 3×8 라벨지 크기로"실습
11–14라벨 인쇄 → USB 스캐너로 품번 입력, 스마트폰으로 QR 읽기시연
14–15"이 라벨을 찍으면 재고가 바뀌는 프로그램, 쉬고 나서 보여드립니다"강의

체크포인트 라벨 5개가 보이고, 바코드 아래 품번이 맞는가. 아티팩트가 안 되는 계정이면 강사 화면으로.

세션 5. Claude Code 시연: 입출고관리

25분 (90분안 동일)

목표 "말로 설명하면 우리 회사에 맞는 프로그램이 만들어진다"를 보여주고, 실제 쓰는 모습까지 연결한다.

분내용방식
0–3오프닝 답 공개: Claude Code와 함께 반나절 만에 만들었다. PRD 화면을 보여주며 "이 문서도 대화로 만들었다"시연
3–9둘러보기: 부품 등록(품번 제안) → 입고 스캔 → 출고 스캔(안전재고 경고) → 재고 현황 → 이력 → CSV를 엑셀로시연
9–16라이브 수정 "대시보드 출고 TOP 5 카드" (대본 부록 C, 7분 넘으면 전환)라이브
16–20서류 사진으로 입고: sample-03 인쇄본을 스마트폰으로 찍기 → 검수 표 → 포장 테이프는 품번 제안(SK-SB-006)으로 등록 → [일괄 입력] → 재고 반영시연
20–24구글 시트 공동 작업: "자재팀은 입고, 생산팀은 출고하면?" → 스마트폰으로 출고 → PC와 구글 시트에 반영시연
24–25정리: 만든 것, 걸린 시간, 사람이 한 일 (원하는 것을 말하고 확인하기)강의
  • Claude Code는 내 PC의 파일을 직접 만들고, 실행하고, 테스트까지 한다. Claude.ai와의 차이.
  • 만드는 순서: 요구사항(PRD) → 만들기 → 테스트 → 고치기. 세션 2·3·4에서 배운 것이 다 들어 있다.
  • 한계: 유료 플랜과 설치가 필요하고, 결과 확인은 사람 몫. 그래서 오늘은 시연.

부록 B. 세션 2·3·4 프롬프트와 정답

세션 2 실습 1: 목록 정리

첨부한 엑셀의 '부품목록' 시트는 여러 사람이 입력해서 표기가 제각각이야. 아래 규칙으로 정리해서 엑셀 파일로 돌려줘.
1. 품번은 SK-분류-세자리번호 형식 (예: SK-AD-005). 대문자, 공백 없이.
2. 품번이 같은 행은 하나만 남겨.
3. 빈 행과 메모 행은 지워.
4. 단위는 EA, BOX, BAG 중 하나로.
5. 거래처는 (주), ㈜, 주식회사, 띄어쓰기를 빼고 회사 이름만.
6. 안전재고는 숫자만. 뜻이 애매한 값은 지우지 말고 '확인 필요' 열을 만들어 이유를 적어.
7. 등록일은 YYYY-MM-DD. 연도가 없으면 2026년.
마지막에 무엇을 몇 건 고쳤는지 표로 알려줘.

세션 2 실습 2: 함수

엑셀 [2016]에서 쓸 수 있는 함수로 알려줘. '부품목록' 시트 A열 품번으로 '단가표' 시트(A열 품번, B열 단가)에서 단가를 찾아 I열에 넣는 수식. 단가가 없으면 '단가 없음'이라고 나오게.
버전정답
2021·365=XLOOKUP(A2,단가표!A:A,단가표!B:B,"단가 없음")
2016 이하=IFERROR(INDEX(단가표!B:B,MATCH(A2,단가표!A:A,0)),"단가 없음") 또는 =IFERROR(VLOOKUP(A2,단가표!A:B,2,FALSE),"단가 없음")
9월 출고량=SUMIFS(출고내역!C:C,출고내역!B:B,A2,출고내역!A:A,">="&DATE(2026,9,1),출고내역!A:A,"<="&DATE(2026,9,30))

조건부 서식: J열이 0이면 행 전체를 연한 빨강 → 11개. 정답 파일 "월별 출고 집계" 시트에 7·8·9월과 검산(2,738 일치).

세션 2 매크로 (강사 PC)

엑셀 VBA 매크로를 만들어줘. 현재 시트를 보고서 서식으로 바꾸는 매크로야. 1행 머리글은 굵게, 연한 파랑 배경. 모든 열 너비 자동 맞춤. F열과 I열은 천 단위 쉼표. A4 가로로 한 페이지에 인쇄되게 설정. 처음 써 보는 사람을 위해 넣는 방법도 단계별로 알려줘.

세션 3: 사진 → 표

첨부한 거래명세서의 품목 표를 읽어서 표로 만들어줘.
열: 귀사 품번, 공급사 코드, 품명, 규격, 단위, 수량
단가와 금액은 빼줘. 표 위에 명세서 번호, 거래 일자, 공급자 상호를 따로 적어줘.
읽기 어려운 칸은 추측하지 말고 '확인 필요'라고 적어줘.

세션 4: 라벨 생성기

품번 목록을 붙여넣으면 Code128 바코드 라벨을 A4에 인쇄할 수 있게 만들어 주는 웹페이지를 아티팩트로 만들어줘.
- 왼쪽에 품번을 한 줄에 하나씩 넣는 입력칸
- 라벨에는 바코드와 그 아래 품번 글자
- A4 한 장에 3열로 배치, [인쇄] 단추
예시 품번: SK-AD-001, SK-PD-003, SK-RM-002, SK-SB-004, SK-CS-001

부록 C. 세션 5 라이브 수정 대본

준비 inventory-app에서 git status가 깨끗한지 확인, npm run dev → localhost:5173. 배포 사이트는 바뀌지 않는다.

대시보드에 "이번 달 출고 많은 부품 TOP 5" 카드를 추가해줘.
품번, 품명, 이번 달 출고 수량을 보여주고, 누르면 그 부품의 이력으로 가게.
테스트도 같이 만들고, 다 되면 빌드해서 확인할 수 있게 해줘.

보여줄 장면 ① 기존 코드를 먼저 읽는다 ② 테스트 → 기능 → 테스트 통과 ③ 새로고침하면 카드 ④ 한마디 더: 수량 옆에 단위(EA, BOX 등)도 붙여줘

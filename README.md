# 부품 입출고관리 (1단계)

「중소기업 실무자를 위한 AI 활용과 업무자동화」 강의 시연용 입출고관리 웹페이지입니다.
요구사항은 [../inventory-prd.md](../inventory-prd.md)를 따릅니다.

## 바로 쓰기

`dist/index.html`을 더블클릭해서 크롬이나 엣지로 엽니다. 설치, 서버, 인터넷이 필요 없습니다.
처음이면 **설정 → 샘플 데이터 불러오기**로 시연용 데이터를 넣으세요.

> 카메라 스캔은 브라우저에 따라 `file://`에서 막힐 수 있습니다. 그럴 때는 아래 `npm run preview`로 실행하세요.

## 개발

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # dist/index.html 한 파일로 빌드
npm run preview        # 빌드 결과 실행 (http://localhost:4173, 카메라 사용 가능)
npm test               # 단위 테스트
npm run test:coverage  # 커버리지 (기준 80%)
npm run test:e2e       # E2E 테스트 (처음 한 번: npx playwright install chromium)
```

## 구조

```
src/
  domain/   순수 로직: 검증, 재고 계산, 입출고·취소 규칙, CSV, 백업, 날짜
  data/     브라우저 저장소, 상태 관리(store), 샘플 데이터
  ui/       화면: views/(화면별), components/(공용), dom.js(이스케이프 템플릿)
  styles/   기본, 컴포넌트, 인쇄(라벨)
tests/unit/ 단위 테스트 (Vitest)
e2e/        E2E 테스트 (Playwright)
```

## 설계 원칙

- **현재고는 저장하지 않고 입출고 기록을 합산해서 계산합니다.** 기록은 지우거나 고치지 않고, 잘못된 기록은 "취소" 기록을 새로 남겨서 바로잡습니다.
- **화면에 출력하는 값은 모두 이스케이프합니다** (`ui/dom.js`의 `html` 템플릿). CSV를 내보낼 때는 수식 인젝션도 막습니다.
- 브라우저 저장소에 접근하다 실패해도 앱이 멈추지 않고, 사용자에게 백업하라고 안내합니다.

## USB 바코드 스캐너

키보드처럼 입력하고 마지막에 Enter를 보내는 일반 스캐너(HID 키보드 방식)면 됩니다.
입고·출고 화면에서는 스캔 칸에 항상 커서가 가 있고, 화면 빈 곳을 누르면 커서가 스캔 칸으로 돌아갑니다.
스캔(Enter)은 부품을 **선택**만 하고, 저장은 **[입력]** 단추로만 합니다. 연속 스캔 모드에서는 같은 바코드를 찍을 때마다 수량 칸이 1씩 늘어납니다.
품번(예: `SK-AD-001`)이 바코드 내용과 같아야 합니다. 라벨은 **부품 관리 → 선택 품목 라벨 출력**에서 만듭니다.
